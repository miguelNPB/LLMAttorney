# LLMAttorney

Bienvenido al repositorio de LLMAttorney, correspondiente al TFG "LLM Attorney: Creación y simulación de casos jurídicos con LLMs para estudiantes de abogacía" de la facultad de informática UCM durante el curso 2025-26.  

Ha sido desarrollado por: Adrián del Pozo Hernández, Miguel Norberto Pérez Ballester, Enrique Juan Gamboa y Javier Murillo González  
Tutorizado por: Carlos León Aznar y Guillermo Jiménez Díaz

## Distribución de carpetas

En este repositorio encontarás los siguientes contenidos en las siguientes carpetas:
- LLMAttorneySimulator: El proyecto de Unity con el simulador.
- LLMAttorneyBuild: Build del proyecto de Unity lista para ser jugada.
- IntermediaryServer: El servidor intermediario que además ejecuta el servidor Ollama. Este servidor debe estar activo para que funcione el proyecto de Unity.
- LLMAttorneyBuild: Build lista para usar del proyecto de Unity.
- TelemetryAnalyzer: Script de Python analizador y graficador de las trazas de telemetría generadas en la ejecución del simulador.
- LLMModelEvaluationAnalyzer: Script de Python analizador y graficador usado en la evaluación de modelos LLM.
- ExtraMaterial: PDFs con contenido extra de este trabajo.
