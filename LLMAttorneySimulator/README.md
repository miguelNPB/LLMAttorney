# LLMAttorney - Simulador (Proyecto de Unity)

En esta carpeta se encuentra el proyecto de Unity del simulador. 

## Rutas a tener en cuenta

Tiene la solución del sistema de telemetría en `/TelemetrySystem`, y los script de Unity y dll compilada del sistema están en `/Assets/Plugins`  

En `Assets/ScriptableObjects` se pueden ver todos los LLMConfig con los textos de los promtps  

En `Assets/StreamingAssets` se encuentra el json y el pdf del caso por defecto.
